# Urdheim v2 — parked

## Brain coin resolution (soft-shill agent loop)

**Problem:** someone tags `@urdheim` asking "what's the ca?" under a post that
won't name the coin — viral or not, especially soft shills (vibes, emojis,
"this thing is going to 10M", chart screenshots with no name).

**Design:** an agent loop, not a single classify call.

1. **Gather** — the post alone is never enough. Pull the thread, the quote,
   the author's last day of posts. Soft shills leak context around
   themselves: yesterday's hint + today's "it's happening" = the coin.
2. **Hypothesize** — ticker fragments, descriptions ("dog coin, 2h old"),
   reply guys naming it in the comments. Each is a candidate, never an answer.
3. **Validate** — every candidate checked against the chain. Launched when?
   Pool size matches the hype? "2h old" + launched 2h ago = strong. Launched
   3 months ago = wrong coin, drop it.
4. **Abstain** — nothing clears the bar, no answer. A wrong coin with our
   name on it kills trust. Never guess an address.

**Later:** chart screenshots need vision (read the pair off the image).
Soft shills love posting a chart with no name — that's where this ends up.

**Spend rule:** cheap-first (regex pre-filter, cached coins), model only on
real ambiguity. Every resolve burns reads + model; budget gates it.
